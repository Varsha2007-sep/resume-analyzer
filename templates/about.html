About AI Resume Analyzer

Career and Skill Development project

Problem

Students struggle to create ATS-friendly resumes. Applicant Tracking Systems filter resumes by keywords and structure, and students rarely know why they are rejected.

Solution

AI Resume Analyzer compares a resume with a job description and provides actionable, honest recommendations, always telling users to add skills only if they genuinely have them.

Project Overview

Problem

Weak resumes are rejected by ATS systems.

Existing Solution

Students manually compare their resume with job descriptions.

Proposed Solution

AI Resume Analyzer automatically compares the resume and job description and gives personalized recommendations.

AI / NLP Usage

  • Text extraction: PDF and DOCX parsing
  • Keyword extraction: frequency and n-gram analysis
  • Skill identification: taxonomy with aliases
  • Similarity analysis: TF-IDF cosine similarity
  • Recommendation generation: rule-based rewriting
